# Formulário de Pedido - Programa de Computador

- **Título do programa:** VEGAbrain (Gene Expression in Human Developmental Brain)
- **Linguagem do Programa:** R e JavaScript
- **Campo de aplicação:** BL02-Genética
- **Tipo de Programa:** TC01-Aplc Tcn Ct (Aplicações Técnico-Científicas)
- **Data da criação do Programa:** 16 de Outubro de 2025
- **Data de publicação do Programa:** Não publicado (Uso Acadêmico/Pesquisa)
- **Resumo Descritivo do PC:** 
A ferramenta "VEGAbrain" consiste em uma aplicação web interativa projetada para visualização espacial e temporal da expressão gênica ao longo do desenvolvimento do cérebro humano. Construído utilizando a linguagem R (plumber, shiny) no back-end e a biblioteca React (JavaScript) no front-end, o sistema aproveita os robustos conjuntos de dados fornecidos pelo *BrainSpan Atlas of the Developing Human Brain*. 

A aplicação permite aos usuários pesquisar por genes específicos, traçando seu padrão de expressão espacial nos tecidos cerebrais ao longo de 5 grandes estágios de desenvolvimento, mapeando-os através do atlas cerebral padrão de Desikan-Killiany. Além do mapeamento univariado, a ferramenta possui capacidades computacionais avançadas, viabilizando análises de enriquecimento através do método GSVA para ontologias e assinaturas gênicas personalizadas. 

O software conta com interfaces responsivas, plotagens gráficas de alta fidelidade baseadas no pacote *ggseg* e recursos de exportação para múltiplos formatos visuais adequados para a literatura científica, preenchendo uma lacuna metodológica essencial na exploração multidimensional de dados neurogenômicos.
